# VELOCITY RUSH

Unreal Engine 5.8.3 で作っている街なかのレースゲームです。

このリポジトリはコード（C++・設定・書き出し用スクリプト）だけを置いています。
アセット（`Content` フォルダ、約 31GB）は含まないため、このままではエディタで開いても遊べません。

## 中身

| フォルダ | 内容 |
|---|---|
| `Source/MyProject` | ゲームの C++ コード（車両・レース進行・NPC の AI・UI など） |
| `Config` | プロジェクト設定（入力・描画・パッケージ化など） |
| `Scripts` | ゲームを書き出すスクリプト（Windows / Mac） |
| `MyProject.uproject` | プロジェクトファイル（使っているプラグインの一覧） |

## 主な機能

- 4 台の車、5 つのレース、朝・昼・夜の 3 つの時間帯
- タイムトライアルと NPC 対戦（強さ 5 段階）
- 2 人対戦（上下の画面分割）
- AT / MT の切り替え、車ごとのメーター、エンジン音
