# VELOCITY RUSH

Unreal Engine 5.8 で作った、街なかを走るレースゲームです。C++ で作っています。

**プレイ動画**: https://youtu.be/7XDwDVDih5M

このリポジトリにはコード（C++・設定・書き出し用スクリプト）だけを置いています。
アセット（`Content` フォルダ、約 31GB）は入っていないので、このままでは遊べません。

## ゲームの内容

- 4 台の車、5 つのレース（3 コース＋逆走）、朝・昼・夜の 3 つの時間帯
- タイムトライアル（自己ベストのゴーストと走れる）
- NPC 3 台との対戦。強さは 5 段階で、勝つと次の段階が解放される
- 2 人対戦（上下の画面分割）
- AT / MT の切り替え、車ごとのメーター、実車録音のエンジン音
- ガードレールや他の車にこすったときの火花と音
- コース記録の保存、画質・音量のオプション

## 苦労したところと解決方法

### 1. NPC が思ったように曲がれない
車の向きと目標点から「どれだけハンドルを切るか」を計算する方法では、NPC が毎回カーブの外側の壁にぶつかりました。
調べると、この車は思ったより曲がりにくい車でした。空中で回転を抑える処理が地上でも効いていたためです。ただ、この手触りは面白いのでそのまま残すことにしました。
そこで NPC のほうを車に合わせました。**走りながら「この速度でハンドルを全部切ると、どれだけ曲がれるか」を測って覚え**、その値から各地点の速度を決めるようにしました。

### 2. NPC の強さを狙ったタイムに合わせる
強さごとにコースの目標タイムを決めました（例：コース1 は NORMAL 3:00 / HARD 2:40）。
NPC は走りながら「実際のタイム ÷ 計画したタイム」を見て、ペースを自分で調整します。1周ごとにラップを測り、ずれた分を次の周で取り戻します。
走行中の速度・ギア・タイヤの接地を記録して、どこでタイムを失っているかを「加速／ブレーキ／滑り／空中」に分けて集計しながら調整しました。

### 3. フレームレートが下がると車が遅くなる
重い設定（30fps 未満）で遊ぶとタイムが悪くなる問題がありました。物理の1回の計算は最大 1/30 秒までなので、それより重いと車の動きだけが遅れ、タイマーは普通に進んでいたのが原因です。
物理をフレームの中で細かく分けて計算する設定（サブステップ）に変え、15fps でも普段とほぼ同じ速さで走るようにしました。

### 4. エンジン音のちらつき
録音を短く切ってつなぐと、つなぎ目で音量が波打ちました（1秒に25回）。
次の切れ端を、**前の切れ端と波の形が一番そろう位置**から始めるようにして、つなぎ目を目立たなくしました（正規化相互相関）。

### 5. エンジンの機能が思ったように動かない
- Chaos Vehicle の `IsMovingOnGround()` は常に false を返します。接地はタイヤ1本ずつの接地情報を数えて判定しています。
- 車がぶつかったときのイベントが、物理アセットの設定のせいで一度も届いていませんでした。物理の状態をつくり直したあとに設定し直すことで、届くようにしました。

## 開発の進め方（AI の使い方）

このゲームは AI（Claude Code）と分担して作りました。C++ のコードの多くは AI が書いています。

自分で担当したこと：
- **企画・仕様の作成**：どんなゲームにするか、モード・コース・車・NPC の強さと目標タイムなどを決めました。
- **マップの制作**：Unreal Editor でコースを作りました。
- **素材の準備**：エンジン音などの音を用意しました。
- **テストプレイからの修正**：実際に遊んで確かめ、気になったところを AI に伝えて直しました。
  （例：NPC の追い上げが強すぎて操作しづらかったので、プレイヤーにかかる追い上げを弱くした）

## ビルド

- Unreal Engine 5.8、Visual Studio（必要なコンポーネントは `.vsconfig` にある）
- `MyProject.uproject` を右クリック →「Generate Visual Studio project files」→ `MyProject.sln` を開いてビルド
- 書き出し：`Scripts/Package_Windows.bat`（Mac は `Scripts/Package_Mac.sh` を Mac 上で実行）

※ アセットが入っていないため、ビルドはできてもゲームとしては動きません。
